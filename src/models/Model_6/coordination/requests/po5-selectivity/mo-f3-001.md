## Do NOT reuse `sweep/eta_in_live_trial.py` as-is

PO-3 measured (`signals/po3-einvasion.md`, F-3) that this harness steps presynaptic release once
per **agent** step (`AGENT_DT = 0.5 s`) and then runs 100 physics steps against one stale
stimulus. The shipped reference `sweep/run_spatial_discovery.py:434-441` steps it **inside** the
physics loop at `physics_dt = 0.005 s`. `PresynapticRelease.step` is a per-timestep Bernoulli
draw, so calling it at 0.5 s intervals removes ~99% of release opportunities:

| | release opportunities / 14 s traversal | expected events |
|---|---|---|
| shipped `run_trial` | 2800 | ~350 |
| L·ETA-3 harness | 28 | **~3.3** |

Measured, same seed/geometry/feature: `max_glu` **0.0000** at the target across a full traversal
(`max_act = 0.9950`) vs **1.0000** corrected; `peak_r` at traversal 2 **0.0571 → 0.1428**.

## Why this is specifically fatal for PO-5

`ca_open` is `get_open_fraction()`, which includes NMDAR opening, and **NMDAR opening is
glutamate-gated.** So this harness runs with NMDARs substantially starved — and **NMDAR is
precisely the channel L·ETA-4 found selectivity SURVIVING in** (silent-synapse NMDAR gain from
plateau: −0.0019, i.e. zero; consistent with Jain 2024's 7±8% no-glutamate control). PO-5's whole
surviving hypothesis is that selectivity lives in `P_product`, which forms only where NMDAR
calcium arrived.

**A selectivity test run on this harness would be measuring a partition under starved NMDARs —
i.e. it would be testing the hypothesis on the exact channel the defect suppresses.** That is a
guaranteed false negative, and the ERR-2 failure class in a third location.

**Requirement:** step release inside the physics loop, and assert `max_glu > 0` at the driven
synapse as a positive control before reading any verdict.
